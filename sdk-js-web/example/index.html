ort-vision-sdk · browser demo

End-to-end ONNX inference in the browser — classification, detection and instance segmentation. Bring your own .onnx model or use the URL preset filled in for the chosen task.

If a file is selected it takes priority over the URL. Default URLs are CORS-friendly Hugging Face presets that change automatically with the task.

        How to run this demo locally
        
    
          
  1. From the sdk-js-web/ directory:
            npm install && npm run build
            (produces dist/index.js, which the demo imports).
    2. 
          
  2. Serve the directory with a static HTTP server. Two options
            that both work out of the box:
            
      
              
    • python3 -m http.server 8000 from
                sdk-js-web/, then open
                http://localhost:8000/example/.
      • 
              
    • VS Code Live Server: right-click
                example/index.html → "Open with Live Server".
                The default port is 5500.
      • 
            
    
          
    3. 
          
  3. Pick a task, paste/upload a model and an image, click Run.
    4. 
        

        

          If nothing runs: open the browser devtools and
          look at the Network/Console tabs. The two most common failures are
          (a) the local SDK at ../dist/index.js isn't
          built yet — fix with npm run build — and
          (b) the model URL has no CORS headers — switch to a
          local file or use a CORS-friendly host
          (Hugging Face, jsDelivr, ONNX Model Zoo).
