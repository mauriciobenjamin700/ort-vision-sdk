        How to run this demo locally
        
    
          
  1. From the sdk-js-web/ directory: npm install && npm run build
    2. 
          
  2. Serve the directory with any static HTTP server, e.g.:
            python3 -m http.server 8000
    3. 
          
  3. Open http://localhost:8000/example/ in a browser
            (Chromium-based browsers give you WebGPU; otherwise it falls back
            to WASM automatically).
    4. 
        

        

          The page loads onnxruntime-web from a CDN and the SDK
          from the local ../dist/ build, so you must run
          npm run build first.
